## 目的
シリアル通信により、2G社の超電導磁力計システムを制御する一連のコード (GUI含む）を作成する

## コードの原則
人間による調整とメンテナンス性を重視した構成にする。関数には原則的に簡潔な説明コメントを付す。

## 超電導磁力計システムの構成

超電導磁力計システムは以下の3コンポーネントからなる

- SQUIDセンサー
試料の磁化を測定する

- サンプルハンドラー
試料を移動させる

- デガウサー
交流磁場を印可する

## 通信規格

### 共通

- BAUD_RATE  1200
- PARITY なし
- STOPBITS 1

### SQUIDセンサー

終端文字: CR

### サンプルハンドラー

終端文字：なし

### デガウサー

終端文字：CR

## 通信コマンド

### サンプルハンドラー
Azzz 加速度を設定 (zzz は 0から127までの整数。デフォルトは5）。数値が大きいほど加速度が大きい。
Bdddd 速度を設定 (dddd は 50 から 5000 の整数。デフォルトは1000)。数値が大きいほど速度が大きい。
Nrrrrrr 移動量を設定。rrrrr は 0  から 16777215 の整数。デフォルトは 0 （移動しない）
+ 移動方向を「プラス」に設定。
- 移動方向を「マイナス」（「プラス」の逆）に設定。
Zrrrrrr 現在位置を rrrrrr として設定する rrrrrr は 0 から 16777215の整数。
G 設定した内容で移動を実行する。移動に伴い現在位置が更新され保持される。
% 移動が正常終了したかを返す
 - 2 パラメータエラー
 - 5 G コマンドが正常終了
 - 7 リミットスイッチで停止（正常終了ではない）
 - G 移動中
Q 移動を途中で停止
Prrrrrr 位置 rrrrrr へ移動するのに必要な移動方向と移動量を取得し設定する。rrrrrr は 0  から 16777215 の整数。
Vc 現在の設定内容を返す。cはどの設定内容を返すかのパラメータ。
 - VA 加速度
 - VB 速度
 - VG 現在の移動であと何ステップ残っているか。停止している場合はゼロを返す。
 - VP 現在位置
