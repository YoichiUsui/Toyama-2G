## 目的
2G社の超電導磁力計システムを、シリアル通信により制御する一連のコード (GUI含む）を作成する

## Project knowledge
- **ファイル構造:**
  - `src/` – Application source code
  - `config/` - Setting files for the software
  - `docs/` – All documentation
  - `scripts/` – manual one-shot tests
