## サンプル測定 GUI

SQUID センサーとサンプルハンドラーを接続し、1番目の試料を測定する GUI。
以下のコマンドで起動する。

```
python scripts/sample_measurement_test.py
```

起動時に `settings/port_names.txt`、`settings/squid_setting.txt`、
`settings/samplehandler_setting.txt` を読み込み、両デバイスへ自動接続する。
接続確認後はサンプルハンドラーの現在位置を表示する。測定前に「ホーム」を
正常完了させると「測定」が有効になり、バックグラウンド測定、試料測定、
バックグラウンド補正後磁化の表示、開始位置への復帰を順番に行う。

移動または測定でエラーが発生した場合は自動復帰せず、ホーム動作以外の操作を
無効にする。ホーム動作を正常完了すると測定可能な状態へ復帰する。測定中の
サンプルハンドラー移動タイムアウトは1回あたり120秒。

従来のSQUIDセンサー単体測定 GUI も `scripts/squid_measurement_test.py` として
残している。このツールはサンプルハンドラーを動かさず、X/Y/Z の単発測定を行う。

## サンプルハンドラー 移動量設定補助ツール

ステップ数と実際の移動距離との関係を実測するための補助 GUI。
以下のコマンドで起動する。

```
python scripts/sample_handler_setting_helper.py
```

レイアウトの例は [`docs/移動量設定補助画面.jpg`](docs/移動量設定補助画面.jpg) を参照。
通信の進行状況をメッセージ欄に逐次表示し、どの段階で失敗したかを追いやすくしている。

動作の流れ:

1. ポートを選んで「選択＆接続」を押すと、ポートを開いた直後に接続確認コマンド `@0,?,` を送る。
   応答は `25\r\n109\r\n` が期待値。数値や改行コードが違えば警告を出して続行し、
   応答が届かなければ接続トラブルと判断してポートを閉じ、操作を受け付けない。
2. 接続確認の後、初期設定として加速度 5 (`A005`)・速度 2000 (`M2000`)・移動方向マイナス (`-`) を送る。
   現在位置は書き換えず、`VP` で読み出して表示する。
3. 移動量・方向を入力して「決定」、続けて「移動」(`G`) を押す。
   移動コマンド送信後だけ、`%` と `VP` による状況確認を一定間隔で行い、
   正常終了 (5)・リミットスイッチ停止 (7)・パラメータエラー (2) の応答が返った時点で確認を止める。
   アイドル中は状況確認をしない (確認コマンドと新規コマンドが衝突するのを避けるため)。
   移動中は「決定」「移動」を無効にし、「緊急停止」(`Q`) のみ押せる。
4. 「ホーム」ボタンを押すと `settings/samplehandler_setting.txt` の `home side` 方向へ速度 500 で
   リミットスイッチまで移動し、到達後は逆方向へ `home position` 分だけ移動する。
   `home side` は `+` または `-`、`home position` は1から10000までの整数が必要。
   リミットスイッチ到達待ちは100秒、ホーム位置への移動は5秒で、時間内に完了しない場合は
   `Q` で停止する。現在位置のゼロ設定は行わない。実機でのホームボタン動作は、このPCでは
   確認できないため、別PCで確認する。
